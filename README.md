# ELMALOO3N AI

مساعد ذكاء اصطناعي بواجهة عربية وهوية سوداء وحمراء.

## حالة المشروع
هذه هي النسخة التأسيسية لواجهة Android باستخدام Kotlin وJetpack Compose. شاشة المحادثة تعمل محليًا، لكن توليد الإجابات الحقيقي لم يُربط بعد.

## المتطلبات
- Android SDK 35
- JDK 17
- Gradle 8.9

## الأمان
لا تضع مفاتيح API داخل تطبيق Android أو داخل مستودع GitHub. يجب أن تتم اتصالات الموديل من خلال خادم وسيط آمن.

## البناء
يتم البناء تلقائيًا عبر GitHub Actions عند الدفع إلى فرع main.
